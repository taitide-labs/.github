# Taitide Labs

专注构建现代化 AI Agent、开发工具链与高可靠性工程基础设施。

## 核心仓库

- **[kitcode](https://github.com/taitide-labs/kitcode)**：基于 Rust 构建的 AI Coding Agent。
- **[agent-browser-kit](https://github.com/taitide-labs/agent-browser-kit)**：面向 `agent-browser` 的扩展 CLI 垫片与 Profile 管理工具。
- **[uv-template](https://github.com/taitide-labs/uv-template)**：基于 `uv`、`ruff`、`ty` 与 `osv-scanner` 的现代化 Python 工程基准模板。
